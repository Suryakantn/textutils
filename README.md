# TextUtils

## Available Scripts

In the project directory, you can run:

### `npm start`

Starts the Vite development server.

### `npm test`

Runs the test suite once with Vitest.

### `npm run build`

Builds the app into the `build` folder for deployment.

### `npm run deploy`

Builds the app and publishes the `build` folder to GitHub Pages.

## Writing tools

- **Diff** compares two versions of text locally in your browser.
- **Grammar** checks English text using LanguageTool. Text is sent to LanguageTool only when you select **Check grammar**; avoid submitting sensitive text.
